# Option A · Family activity feed

The parent opens one chronological activity feed with direct actions for alerts, requests and location. The child starts with time remaining, the next routine and their own request history.

The frames use fictional data. The two RTL previews reuse strings from the existing OSRA Parent and iPhone Child apps.
