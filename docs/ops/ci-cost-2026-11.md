## Official 2026 USD rate model

GitHub's included-compute model, per the current official billing documentation. The per-minute rates
below are the reduced standard-runner rates **effective 2026-01-01** (a separate fact from the
included-compute documentation, which is current as of this writing):

- **Free plan:** $12/month of included GitHub Actions compute.
- **Pro plan:** $18/month of included GitHub Actions compute.
- Included compute is a monthly dollar allowance, **not** a minute quota.

Per-minute rates for private-repository compute on standard runners, after the included allowance:

| Runner | $/minute |
|---|---:|
| Linux x64 | $0.006 |
| Linux arm64 | $0.005 |
| Windows x64 | $0.010 |
| macOS | $0.062 |

Source URLs (the official pages the research used):

- <https://docs.github.com/en/billing/managing-billing-for-your-products/managing-billing-for-github-actions/about-billing-for-github-actions>
- <https://docs.github.com/en/actions/learn-github-actions/usage-limits-billing-and-administration>

## Estimates (private-repo pricing, 31-day window)

| Model | Estimate | What it means |
|---|---:|---|
| **Untrimmed** | **≈ $666.26** | The 31-day measurement priced at the rates above, before any #613 change. macOS (`ios-ci`, the 10× runner) and the Windows desktop suite are **measured**; the Linux bulk is **scaled from the 31-day sample** (the largest Linux consumers are `ci`, `child-android`, `parent-app`, `verified-gate`, `workflow-lint`). |
| **Trims 1 + 2** | **≈ $392** | Trim 1 (iOS CI pushes `main`-only instead of every branch) removes most of the repeated 10× macOS minutes; trim 2 (the six build suites move from daily to weekly Monday 02:11) cuts the scheduled Linux/Windows minutes to ~1/7. |
| **Gradle cache** | **≈ $379–385** | Trim 3: `gradle/actions/setup-gradle` pinned to the full v4.4.3 commit SHA in `child-android.yml` reuses the Gradle dependency/build cache, so the 77.14h Android budget drops. The range is the estimate either side of the expected cache-hit improvement. |
| **Current-workflow-only** | **≈ $323** | Only the current PR-suite set (`api`, `parent-app`, `child-android`, `agent-desktop`, `ai-engine`, `api-image`, `ci`, `ios-ci`) with its measured minutes, excluding the auxiliary workflows (`verified-gate`, `workflow-lint`, `main-guard`, `terraform`, etc.). |

**Measured vs estimated.** The macOS figure is anchored in the measured `ios-ci` actual duration
(114.57h, 501 macOS runs) and `agent-desktop` (42.77m, 29 Windows runs). Linux minutes are the largest
category and are **derived** — Linux-equivalent minutes, computed by applying the per-minute rates to
the measured durations — not a number GitHub reported; macOS/Windows are the harder, directly measured
numbers.
