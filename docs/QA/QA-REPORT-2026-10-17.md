## 2. Security findings raised and closed today

- **#83 F1 (blocking, by Claude):** the #80 exemption matched a package *name* a child can choose, so
  `com.evil.dialer` was a lock bypass and `com.android.phonebook.game` matched `startsWith("com.android.phone")`.
  Fixed by role + system flag (`PackageFacts`, `TelecomManager` role holders, system handlers of the
  emergency-dialer and `ACTION_DIAL` intents), prefix on a segment boundary, caches refreshed on package
  change. Four fails-before tests; 33 suites / 219 tests / 0 failures.
- **#87 (found on hardware, open):** the overlay can cover the bouncer and lock the *owner* out of their
  own PIN; recovery needed `resume` from the server. A/B/C decision open, default B (never draw over the
  keyguard). S2 gates it.
