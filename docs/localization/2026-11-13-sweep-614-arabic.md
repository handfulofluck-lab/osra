# Arabic for the English text that has none yet (K31's sweep, #614)

Arabic Language Bureau, 13 Nov 2026. Decided under Karim's rule of 13 Nov ("The bureau should take the decision after its internal thorough process to decide based on comparison and standards"). Source of the sweep: `1ed24f83`. The Bureau read every line in its code before writing.

**How to use this file.** Each Arabic value is final wording. Copy it byte for byte. Do not write or adjust Arabic yourself; if a line does not fit the code (a different placeholder, a sentence built from pieces), ask on #604. Placeholders are written Android style (`%1$s`, `%1$d`); use the same order in other platforms. Where a count is involved the Arabic needs all plural forms, given below.

**Words used throughout** (all from the word list in `docs/LOCALIZATION.md`): the app on the child's device is «تطبيق أسرة للأطفال»; the parent's app is «تطبيق أسرة» or «تطبيق الوالدين»; to a child, "your parent" is «والدك أو والدتك»; device admin «مسؤول الجهاز»; web filter «تصفية المواقع»; pairing «إقران»; the PIN is «رمز PIN للوالدين»; SOS «الاستغاثة»; places (geofences) «الأماكن». Buttons that do something are verbs («أقرن هذا الجهاز», «احفظ الرمز» are the approved models); Cancel, Close and Back are nouns, as Android itself writes them («إلغاء», «إغلاق», «رجوع» in `frameworks/base`).
