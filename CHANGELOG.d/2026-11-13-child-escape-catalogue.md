### Testing — child-escape catalogue, schedule and Android escape probe
- `docs/testing/CHILD-ESCAPE-CATALOGUE.md`: what a child tries to get past each gate screen (ring, lock, block, bedtime, pause, parent PIN, tamper guard, shield) on Android, the parent app, OSRA Kids, Windows and macOS, and what must still hold. Written after the maintainer found two ring-screen faults on the Flip4 that happy-path device runs had missed (#734, osra-security#17).
- `docs/testing/ESCAPE-TEST-SCHEDULE.md`: every row attacked by at least two AI model families, device slots so the Flip4, test iPhone, MacBook and Windows VM are never double-booked, a full run per release candidate, and a daily pass/fail summary.
- `scripts/hardware/android-escape-probe.sh`: plays the child against a gate that is already up (Home ×N, Back, Recents, shade, quick settings, volume, assistant, refused PIN inputs; power key opt-in) and measures that the gate returns within the budget, the ring keeps sounding and the agent's process is unchanged. Never touches the clock, `dpm`, the lock-screen PIN or the parent PIN.
