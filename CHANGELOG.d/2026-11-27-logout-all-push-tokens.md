### API — account-wide sign-out atomically retires parent push registrations
- `revokeAllRefreshTokens` (`POST /v1/auth/logout-all`, password reset, MFA verification/recovery/reset, and refresh-token reuse revocation) now increments `Parent.sessionVersion` and deletes the parent's `ParentPushToken` rows in one atomic database transaction serialized on the `Parent` row (`FOR NO KEY UPDATE`), preserving Redis cache reconciliation and best-effort socket revocation signals, and `POST /v1/me/push-token` validates session liveness against that locked `Parent` generation before `upsert`.
