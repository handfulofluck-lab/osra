- Production hardening, batch B (#766 items 1, 3, 13; gate #637): production keeps no secret values in Terraform state. RDS manages the master password, and `production-secrets.sh` writes JWT_SECRET, VAULT_KEY, the API's database password and a Redis AUTH token straight into Secrets Manager. The API connects as `osra_api` (rows only) with verified TLS (`DATABASE_TLS_VERIFY=required`). Migrations run in a separate db-admin task. The state bucket uses a customer KMS key and refuses every principal except the deploy role.
