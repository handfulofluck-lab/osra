- **Parent app (UX-final switches, #1179 / #1206):** The P-09, P-12, P-15, P-17 and P-20 switches now fall back to `OSRA_UX_FINAL` like P-07 and P-14 already did, and the release appbundle, the unsigned iOS build and the staging APK script pass `--dart-define=OSRA_UX_FINAL=true`. Before this, CI test builds passed only `API_BASE`, so every merged UX-final screen stayed on its old layout in the build Karim tests. A new test (`ux_final_switch_test.dart`) fails if any `OSRA_UX_Pxx` switch is added without the fallback. Each per-screen switch can still be forced off with `--dart-define=OSRA_UX_Pxx=false`.
