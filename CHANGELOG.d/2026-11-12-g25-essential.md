### API — the installed-apps probe accepts the `essential` display field (#644)
- `qa-probe.mjs` G25 expected the parent read of `/v1/devices/:id/apps` to return exactly
  `packageId`/`label`/`isSystem`; since issue #199 added the display-only `essential` column and the
  read route returns it, the probe failed on `main` (`keys=essential,isSystem,label,packageId`).
- G25 now expects the four-key shape and pins `essential: true` for `com.android.settings` and
  `essential: false` for `com.example.game`, while keeping the `isSystem` assertion.
