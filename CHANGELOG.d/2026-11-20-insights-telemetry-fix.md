### Child agent & API — restore social alerts, incognito/DoH filtering, search safety alerts, and foreground usage telemetry (#830, #863, #938, #939, #941)
- **Signed social and content uploads (#863, #938):** `SignatureInterceptor` now signs `/v1/social/scan`, `/v1/content/search-event`, and `/v1/content/youtube-watch` alongside `/internal` routes so `ScanFlushWorker` batches no longer fail with HTTP `401 missing_signature`.
- **Chat screen capture & IME events (#938):** `SocialCapture` resolves the active monitored app from the current window/foreground package (`resolveMonitoredApp`) instead of dropping IME events, walks `rootInActiveWindow`, and `SocialHeuristics.extractCandidates` collects recent non-empty messages so long older messages cannot shadow short harmful replies.
- **Search safety reporting & local fallback union (#939):** Added `SearchQueryParser` and Full-flavor `AccessibilitySearchCapture` (Play flavor stays a `NoopSearchCapture` stub per ADR-0039) wired into `AccessibilityMonitorService` (`POST /v1/content/search-event`), and changed `POST /v1/content/search-event` on the API to union AI and expanded EN/AR `SEARCH_LOCAL_PATTERNS`.
- **Browser DoH canary/bootstrap sink (#941):** `DnsFilterPolicy` sinks known DNS-over-HTTPS bootstrap/canary hosts (`REASON_DOH_BYPASS`) while web filtering is active so browsers fall back to the local VPN DNS filter even in incognito mode, without inflating parent block-attempt alerts.
- **Foreground usage accounting (#830):** `UsageReporter` closes the previous app's active window and skips `com.android.systemui` in both `recordForeground` and `backfillFromUsageStats` so system UI overlays do not consume foreground app usage minutes.
