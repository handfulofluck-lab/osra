### Child agent, parent app & API — restore social alerts, incognito/DoH filtering, opt-in search safety reporting, and foreground usage attribution (#830, #863, #938, #939, #941)
- **Window-verified social & search capture (`osra-security#44`):** `SocialCapture` and Full-flavor `AccessibilitySearchCapture` verify window ownership across `activeRoot`, `event.packageName`, `event.source` (acquired lazily inside `try/finally` after fast gates), and descendant `node.packageName == expectedPackage` via `WindowOwnershipPolicy` before reading any accessibility text, flags, or children, and `SocialHeuristics.extractCandidates` collects recent non-empty messages so older text cannot shadow short harmful replies.
- **Opt-in search reporting, durable queue & local fallback union (#939, `osra-security#45`, `#53`-`#56`):** `RuleRepository.searchMonitoringEnabled()` defaults to `false` until `RuleSet.searchMonitoring == true` is explicitly granted (`parent-app` exposes an explicit `Search safety` opt-in toggle via dirty-tracked narrow `PATCH` writes in `SocialScreen` so unrelated monitoring/allowlist saves cannot reverse an opt-out; `services/api` omits absent `searchMonitoring` on `PATCH` updates and enforces opt-in + drops URL data server-side); Full-flavor `AccessibilitySearchCapture` (Play remains `NoopSearchCapture` per ADR-0039) enqueues only confirmed submitted queries through durable `pending_scans` (`SocialScanQueue`), which honors `ConsentState` pause and requires verified pre-grant backlog cleanup before advancing the stored epoch, purges all pending search rows (`PendingScanDao.deleteBySource`) on opt-out, and schedules delayed batch flushes without self-cancellation; `POST /v1/content/search-event` derives critical alert categories from the full AI/local union and prioritizes critical categories under concern bounds.
- **Browser DoH canary/bootstrap sink (#941):** `DnsFilterPolicy` sinks known DNS-over-HTTPS bootstrap/canary hosts (`REASON_DOH_BYPASS`) while web filtering is active so browsers fall back to the local VPN DNS filter even in incognito mode, without inflating parent block-attempt alerts.
- **Foreground usage attribution (#830):** `UsageReporter` delegates transition state to `ForegroundSessionTracker`, clearing `activeForegroundPkg` on `com.android.systemui`, own overlay windows, and screen-off events so system UI never retains foreground usage attribution.
