- Parent Apps tab lists every app on the child's Android phone with its own icon and name (no package ids), a one-tap switch to block or allow with Undo, search, Blocked and Time limits filters, and a sheet for daily limits. The child agent sends each app's launcher icon (72 px WebP or PNG) in the installed-apps report; the API checks and stores it (migration 0041) and returns it as `iconUrl`. English and Arabic.
