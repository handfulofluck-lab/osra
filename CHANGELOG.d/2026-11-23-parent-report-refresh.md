### Parent app — Reports refresh and wellbeing scores (#830)

- Parents can refresh the open report. Returning from history or reopening a reporting window fetches the latest counts.
- Reports keeps the screen-time total visible when the per-app breakdown is unavailable.
- Refreshing the dashboard updates wellbeing scores. A missing score no longer displays as zero. When a daily limit is disabled, screen time incurs no usage penalty.
- Verified with synthetic API and Parent widget tests. Handset acceptance remains open.
