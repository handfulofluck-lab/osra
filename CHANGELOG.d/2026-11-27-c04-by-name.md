### API — the child's "what changed" feed can say which adult made a change (C-04, #1237, #1179)
- Rule changes, bonus time, wind-down, pause and resume internet, pause and resume, and lock and unlock now
  carry `byName`: the display name of the signed-in adult who made the change, stamped by the server.
- A `byName` sent by the client is dropped and never trusted. System changes (routines, jobs) and adults
  without a usable name carry none, so the phone shows its "your parents" fallback.
- A rules update still waiting on the phone takes the latest adult's name when a second adult changes the
  rules before the phone picks it up.
- Overlapping rule saves by two adults are decided one at a time per phone, and the waiting update is
  replaced only if it is still waiting at the revision that was read. An older save never replaces a newer
  adult's name, even when the phone already picked up the newer update.
