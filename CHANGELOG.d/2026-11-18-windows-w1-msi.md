### Windows agent — WiX v5 per-machine MSI and compile-time `OsraApiBase` switch (#927, plan 5.4)
- Adds `apps/agent-desktop/installer/OSRA.wxs` and `Build-Msi.ps1` to package the self-contained W1 runtime (`OSRA.Service.exe`, `OSRA.exe`, `OSRA.Agent.dll`, `reset-proxy.bat`) into `win-x64` and `win-arm64` per-machine MSIs (`ProgramFiles64Folder\OSRA`, `OSRA Service` running as `LocalSystem` with 5-second crash-restart recovery, `HKLM\...\Run\OSRA` tray startup, and `SYSTEM`/`Administrators` install-directory write ACLs).
- Adds a validated compile-time `<OsraApiBase>` MSBuild property in `FamilyShield.Agent.csproj` defaulting strictly to `https://api.osratech.com` (`error OSRA001` on non-HTTPS or invalid values; staging builds pass `-p:OsraApiBase=...` without re-enabling runtime endpoint overrides).
- Updates `.github/workflows/agent-desktop.yml` to build and upload the unsigned `win-x64` and `win-arm64` MSIs (`OSRA.Windows-W1-msi-unsigned`) and hardens `TrayServerWorker.SessionSlot` stop/dispose draining.
