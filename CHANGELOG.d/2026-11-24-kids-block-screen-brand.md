- OSRA Kids on iPhone blocks an app or a website with **OSRA's own screen** instead of iOS's: the mark (the ring and the dot, drawn from `docs/design/brand/mark.svg`), the `page` background, `primary` buttons with `onPrimary` labels, `ink` title and `muted` subtitle, all from the ADR-0038 tokens with light and dark pairs. The subtitle is now **always** present — the window line when a bedtime or routine holds the app, otherwise the new `block_subtitle_default` ("Tap Request access to ask your parent.", Arabic from the Arabic Language Bureau on #604) — because an empty subtitle is what let iOS write its own "You cannot use … because it is restricted". Colours and the mark are drawn in code rather than shipped as a raster: this repository is built without Xcode or an SVG rasteriser, so a hand-exported PNG could not be regenerated or checked. `ShieldBrandTests` compares every colour against `docs/design/tokens.json`, every mark number and colour against `mark.svg` and `mark-dark.svg`, and computes the WCAG ratio for each text/ground pair so the 4.5:1 floor is measured rather than asserted. **Not verified here:** how the screen looks on a device — that is the iPhone row, and the UI/UX Bureau's pictures (#881).
