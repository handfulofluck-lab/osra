- API (#1139): Social alert pushes are grouped per child and app. The first 3 flagged messages each push, then the rest are counted into one summary push per 10-minute window, even across several contacts. Critical messages and severity step-ups still push at once. Both numbers are settings (`SOCIAL_ALERT_FIRST_PUSHES`, `SOCIAL_ALERT_SUMMARY_MINUTES`). Alert metadata gains `pushDeliveryId` and `pushDeliverySeq`, which change only when a push really fires, so the parent app can tell a new notification from a silent count update.
