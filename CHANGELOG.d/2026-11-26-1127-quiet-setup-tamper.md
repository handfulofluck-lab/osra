### Android + API + Parent — first phone setup no longer pages generic tamper noise (#1127)
- New pairings use a server-owned 30-minute setup window. Only tamper events tied to a grant currently reported missing are held for security audit; they do not push, publish, appear in alerts or exports, or get acknowledged. SOS and unrelated tamper events remain visible.
- Authenticated all-required telemetry emits one protected alert. A shared poll/scheduler evaluator emits one missing-steps alert at 30 minutes. Existing paired devices are backfilled without an alert burst, and the approved data-cleared path keeps one named reinstall alert.
- Parent Phone setup shows localized steps left while incomplete and protected afterward, with repair rows for later missing grants. Completion, timeout and data-clear alerts have English/Arabic titles and bodies, localized grant labels and generic lock-screen bodies.
- ADR-0047 and migration 0046 document the server state and paired-device backfill. Focused suites include fail-first held-event, completion, retry, poll/scheduler, EN/AR and malformed-parameter coverage. Independent R3/security and Bureau review plus full live verification are recorded on the PR when complete; no handset claim is made here.
